📥 Instruções: Baixar Fontes para Offline

⚠️ IMPORTANTE: As fontes Clash Display e Satoshi precisam ser baixadas manualmente e colocadas na pasta assets/fonts/.

Passo 1: Acessar Fontshare

Vá até o site do Fontshare para baixar as fontes:

https://www.fontshare.com/fonts/clash-display

https://www.fontshare.com/fonts/satoshi

Passo 2: Baixar Arquivos

Para cada fonte, baixe os arquivos .woff2 nas seguintes variantes:

Clash Display:

  • ClashDisplay-Regular.woff2
  • ClashDisplay-Medium.woff2
  • ClashDisplay-Semibold.woff2
  • ClashDisplay-Bold.woff2

Satoshi:

  • Satoshi-Regular.woff2
  • Satoshi-Medium.woff2
  • Satoshi-Bold.woff2
  • Satoshi-Black.woff2

Passo 3: Renomear e Colocar na Pasta

Crie a pasta assets/fonts/ (se não existir) e coloque os arquivos com os nomes esperados pelo CSS:

  • assets/fonts/clash-display-v7-normal.woff2 (pode usar qualquer variante normal)
  • assets/fonts/satoshi-v4-normal.woff2 (pode usar qualquer variante normal)

Passo 4: Verificar

Depois de baixar e mover os arquivos, abra a página index.html no navegador e verifique se as fontes estão carregando corretamente.

Alternativamente, você pode:

  1. Manter o link CDN do Fontshare (funciona apenas com internet)
  2. Usar fontes do sistema como fallback (já configurado: Clash Display → Satoshi → Inter → system-ui)
✅ Se estiver tudo correto: O site funcionará offline na feira ABF com as fontes locais.
